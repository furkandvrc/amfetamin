# amfetamin

**by furkandvrc**

Windows ve macOS için DPI bypass aracı.

🌐 [English](README.md) · [Türkçe](README.tr.md) · [Deutsch](README.de.md) · [Русский](README.ru.md) · [Español](README.es.md)

## İndir

[Releases](https://github.com/furkandvrc/amfetamin/releases/latest) sayfasından platformunuzu seçin:

| Platform | Dosya |
|----------|-------|
| Windows | `amfetamin-windows.zip` |
| macOS | `amfetamin-macos.zip` |

### Windows

1. Zip arşivini açın
2. **Amfetamin.exe** dosyasını çalıştırın (UAC onayı)
3. **Panel** sekmesinde **CIHAZA KUR** düğmesine tıklayın

### macOS

1. Zip arşivini açın
2. Terminal'de klasöre girip çalıştırın:

```bash
chmod +x setup.sh amfetamin diagnose.sh lib/*.sh
sudo bash amfetamin install
```

Detaylı kurulum: [macos/README.tr.md](macos/README.tr.md)

## Özellikler

- Otomatik TTL ayarı
- Açılışta otomatik başlatma
- Gelişmiş loglama ve teşhis araçları
- Windows: sekmeli masaüstü arayüzü
- macOS: menü çubuğu uygulaması
