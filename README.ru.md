# amfetamin

**by furkandvrc**

Инструмент обхода DPI для Windows и macOS.

🌐 [English](README.md) · [Türkçe](README.tr.md) · [Deutsch](README.de.md) · [Русский](README.ru.md) · [Español](README.es.md)

## Загрузка

Выберите платформу на странице [Releases](https://github.com/furkandvrc/amfetamin/releases/latest):

| Платформа | Файл |
|-----------|------|
| Windows | `amfetamin-windows.zip` |
| macOS | `amfetamin-macos.zip` |

### Windows

1. Распакуйте архив
2. Запустите **Amfetamin.exe** (подтвердите UAC)
3. На вкладке **Panel** нажмите **CIHAZA KUR**

### macOS

1. Распакуйте архив
2. В терминале в папке архива:

```bash
chmod +x setup.sh amfetamin diagnose.sh lib/*.sh
sudo bash amfetamin install
```

Подробная инструкция: [macos/README.md](macos/README.md)

## Возможности

- Автонастройка TTL
- Автозапуск при загрузке системы
- Расширенное логирование и диагностика
- Windows: вкладочный интерфейс
- macOS: приложение в строке меню
