# amfetamin

**by furkandvrc**

DPI-Bypass-Tool für Windows und macOS.

🌐 [English](README.md) · [Türkçe](README.tr.md) · [Deutsch](README.de.md) · [Русский](README.ru.md) · [Español](README.es.md)

## Download

Wählen Sie auf der [Releases](https://github.com/furkandvrc/amfetamin/releases/latest)-Seite Ihre Plattform:

| Plattform | Datei |
|-----------|-------|
| Windows | `amfetamin-windows.zip` |
| macOS | `amfetamin-macos.zip` |

### Windows

1. Zip-Archiv entpacken
2. **Amfetamin.exe** starten (UAC bestätigen)
3. Im Tab **Panel** auf **CIHAZA KUR** klicken

### macOS

1. Zip-Archiv entpacken
2. Im Terminal im entpackten Ordner:

```bash
chmod +x setup.sh amfetamin diagnose.sh lib/*.sh
sudo bash amfetamin install
```

Ausführliche Anleitung: [macos/README.md](macos/README.md)

## Funktionen

- Automatische TTL-Anpassung
- Autostart beim Systemstart
- Erweiterte Protokollierung und Diagnose
- Windows: Desktop-Oberfläche mit Tabs
- macOS: Menüleisten-App
