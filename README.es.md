**by furkandvrc**

Herramienta de bypass DPI para Windows y macOS.

🌐 [English](README.md) · [Türkçe](README.tr.md) · [Deutsch](README.de.md) · [Русский](README.ru.md) · [Español](README.es.md)

## Descarga

Elige tu plataforma en [Releases](https://github.com/furkandvrc/amfetamin/releases/latest):

| Plataforma | Archivo |
|------------|---------|
| Windows | `amfetamin-windows.zip` |
| macOS | `amfetamin-macos.zip` |

### Windows

1. Extrae el archivo zip
2. Ejecuta **Amfetamin.exe** (acepta el aviso UAC)
3. En la pestaña **Panel**, pulsa **CIHAZA KUR**

### macOS

1. Extrae el archivo zip
2. En Terminal, dentro de la carpeta extraída:

```bash
chmod +x setup.sh amfetamin diagnose.sh lib/*.sh
sudo bash amfetamin install
```

Instrucciones detalladas: [macos/README.md](macos/README.md)

## Características

- Ajuste automático de TTL
- Inicio automático al arrancar
- Registro avanzado y herramientas de diagnóstico
- Windows: interfaz de escritorio con pestañas
- macOS: aplicación en la barra de menú
